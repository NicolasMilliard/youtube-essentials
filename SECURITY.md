# Security policy

## Supported versions

Security fixes target the latest published version of YouTube Essentials for
each supported browser. Older versions are not maintained separately.

Reports affecting the development version on `main` are also welcome.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/NicolasMilliard/youtube-essentials/security/advisories/new).

Do not disclose vulnerability details in public issues or pull requests.

Include:

- The affected extension version and installation source
- Your browser version and operating system
- Steps to reproduce the vulnerability
- The potential impact
- A minimal proof of concept, if available

Avoid including passwords, authentication tokens, or other personal information.

If the private reporting form is unavailable, open an issue requesting a private
security contact without including vulnerability details.

## Disclosure

Please allow time to investigate the report and coordinate a fix before
publishing technical details.

This project is maintained in spare time, so response and resolution times
cannot be guaranteed.

## Other reports

For ordinary bugs and feature requests, use the repository's issue templates.
For information about data handling, see [PRIVACY.md](PRIVACY.md).
